# Rice Leaf Disease Detection using CNN

## Project Overview
This project uses Convolutional Neural Networks (CNN) to classify rice leaf diseases from images.

## Objectives
- Perform exploratory data analysis on rice leaf images.
- Build a CNN model to classify rice leaf diseases.
- Study the impact of data augmentation.
- Compare model performance and discuss the best model for potential deployment.
- Document challenges and solutions.

## Dataset
The dataset contains 120 images across three classes, with 40 images per class:
- Leaf Smut
- Brown Spot
- Bacterial Leaf Blight
